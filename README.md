# File-Handling-in-Python
In Task 1:
          I have created a file named "sample.txt" beforehand and then the following concepts were used:
          try-catch block : To handle errors if the file doesn't exist.
          r -mode : To only read the contents of the file.
          readline() function: To read the contents of the file line by line.
In Task 2 :
          I have appended user input text in a file named "output.txt" using the following concepts:
          a - mode : Creates a file if it doesn't exist beforehand and allows to append data in the file
          with : automatically opens and closes the file.
          r-mode : to read the final content of the appended data.
